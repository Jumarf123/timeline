# Timeline 0.2.0 — проверка релиза

Команда релиза: `./scripts/Build-Release.ps1`, без пропуска UI-тестов. Код завершения — 0. Итоговые файлы: `dist/Timeline.exe`, `dist/Timeline-0.2.0-Windows-x64.zip`, `dist/SHA256SUMS.txt`.

Сквозной тест проверяет поиск по всему файлу, даты и числа, фильтры, страницы, виртуальные строки, перестановку/закрепление/ширину столбцов, масштаб, настройки, RU/EN, диапазоны мышью/Shift и копирование за пределами экрана. Проверены TXT/LOG, перенос строк и его сохранение, выделение/копирование/поиск текста, переход между фрагментами и номера строк, читаемый DAT, режим Hex, переключение decoded/raw в ячейках, точность JSON/JSONL и Markdown с исходником.

Дополнительные проверки форматов:

- EVTX 256 MiB: 102144 записи, 32 столбца, импорт 2,782 с. Значения всех полей, ID, время и порядок каждой записи совпали с `evtx::EvtxParser`. Это искусственно увеличенный fixture; скорость других журналов зависит от структуры и машины.
- Малый EVTX: 399 записей, полное совпадение с reference parser. Повреждённые/оборванные блоки и отмена покрыты отдельными тестами.
- Предоставленный Autoruns ARN: 1741 запись, 16 столбцов, импорт 0,628 с. Неизвестные бинарные поля сохранены; предупреждение отображается.
- Созданная через Windows ESENT база: длинное Unicode-поле, многозначная колонка и бинарное поле. Локально проверен исходный hex-пример пользователя: URL извлечён полностью, исходные байты совпали, файл базы после чтения не изменился. Публичная тестовая fixture содержит синтетический URL на example.test с той же структурой UTF-16LE, бинарным префиксом и хвостом; исходный пример в репозиторий не включён.
- Извлечение текста: UTF-8, UTF-16 LE/BE, произвольное смещение, кириллица, surrogate pairs, BOM, NUL, повреждённые последовательности, длинные строки, границы потокового чтения и 14 текстовых форм hex.
- Проверены raw-колонки и коллизии имён, DAT с повреждённой структурой/кодировкой и бинарными данными после 128 KiB текста, SQLite BLOB, XML с комментариями/сущностями/пробелами, USN, разделители/многострочные CSV, JSONL-массивы и большие целые числа.
- Чтение занятого тестового файла через временную копию, запрет записи в исходник, удаление временной копии, разбор ADS/USN-путей и Windows quoting при передаче аргументов проверены тестами. Само подтверждение UAC и доступ ко всем защищённым системным файлам не автоматизировались.

Скриншоты UI-проверок находятся в `test-results/` (локальные артефакты, исключены из Git). Поддерживаемые структуры и ограничения описаны в [FORMATS.md](FORMATS.md). Извлечение вероятных строк из неизвестного бинарного формата не является полной расшифровкой или восстановлением сжатых/зашифрованных данных.
